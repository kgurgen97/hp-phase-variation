# Study scope

This project evaluates whether repeat-length variation at candidate phase-variable loci in *Helicobacter pylori* can be measured reproducibly from public short-read whole-genome sequencing data and explored in gastric disease cohorts.

The publication-facing analysis has two components.

## Technical component

1. Build a multi-reference catalogue of repeat loci.
2. Define read-level anchoring and repeat-length calling rules.
3. Quantify callability and sequencing-platform effects.
4. Validate short-read repeat-length calls against high-accuracy long-read sequence where suitable truth data are available.
5. Restrict downstream analyses to loci that satisfy the frozen technical eligibility criteria.

## Pilot disease component

The disease analysis is intentionally limited to within-cohort contrasts for which the available metadata and sample structure are defensible. Cross-study pooling is avoided when disease state is entangled with geography, sequencing platform, biopsy site, or cohort.

The pilot analysis is not presented as a definitive test of phase-variable adaptation across the Correa cascade. Publicly available cohorts did not provide a sufficiently large, independently mapped discovery-and-replication design under the frozen criteria.

Accordingly, null or inconclusive pilot results are retained as such and are not used to change locus thresholds, disease definitions, or sample inclusion rules.
