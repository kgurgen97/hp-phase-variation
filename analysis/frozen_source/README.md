# Frozen generating source

This directory is a curated export of the exact tracked generating scripts from the authoritative development archive at Project A closeout commit `5660954675c6f9fa89a542aca5a5bce87813e648`.

The exported scripts are preserved verbatim so publication packaging does not silently alter frozen analytical logic. Their internal G5-G8 paths are historical provenance; publication-facing inputs and outputs use normalized paths documented in `analysis/path_map.tsv`.

The export excludes debug scripts, superseded implementations, raw sequencing data, GPT/Claude handoff files, orchestration state, TODO files, and internal decision chatter.
